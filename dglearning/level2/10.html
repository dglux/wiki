10. Using Symbols

  1. Symbols are a great way to automate styling with similar design components. The next section will go through and standardize different elements of our design so that they can be reused and formatted easily.
  2. First set: System Info
    1. Right click on model > Convert to Symbol
      1. Name: “infoItem”
      2. Click OK
    2. Right click on model > Edit Properties (Note: Available now because it is a symbol)
      1. Drag in three string properties
        1. Name: “label”
        2. Name: “value”
        3. Name: “fontColor”
      2. Click check mark to save symbol
      3. Notice “infoItem” in symbols area
    3. Select model
      1. Label: “Model”
      2. Value: bound from data point
      3. fontColor: bound from output of setFontColor in toggle dataflow
    4. Right click on model > Edit Properties
      1. Bind label to text field of label
      2. Bind value to text field of value
      3. Bind fontColor to font color of each text component
    5. Duplicate model and redo for each of the other System Info line items
    6. Preview mode > change to night theme
    7. Change card backgrounds to match header
      1. Change font color in toggle and set groups
  3. Second set: Charts
    1. Convert chart to symbol
      1. Right click on topChart > Convert to Symbol
        1. Name: “metricChart”
    2. List Selection
      1. Right click topChart > Edit Symbol
      2. Replace chart title with a list dropdown
        1. List options
          1. CPU Usage:/data/systemDataHistories/CPU Usage
          2. Redo for every other data point, commas w/ no space for separation
        2. Font: lato-bold
        3. Font Size: 24px
        4. Modify > Edit Properties
          1. Drag in string property
            1. Name: “fontColor”
            2. Bind to font color of list component
          2. Drag in string property
            1. Name: “bgColor”
            2. Will be used later
      3. Delete title text component
      4. Click check mark to save symbol
      5. Bind setFontColor from toggle dataflow to fontColor property
      6. Bind setBGcolor from toggle dataflow to bgColor property
    3. Loading Histories/Time Range Properties
      1. Right click topChart > Edit Properties
      2. Drag in daterange property
        1. Name: “selectedRange”
      3. Drag in number property
        1. Name: “rangeDuration”
      4. Click OK to save symbol
      5. Save page
      6. Select Date Range Picker
        1. Double click on bind of value
        2. Double click on bind of duration
      7. Select topChart
      8. Bind value to selected selectedRange symbol property
      9. Bind duration to rangeDuration symbol property
      10. Right click on topChart > Edit Symbol
      11. Open dataflow for Chart
        1. Delete realtime recorder
        2. Drag in loadHistories block
        3. Select list in outline, bind value to path of loadHistories block
        4. Modify > Edit Properties
        5. Bind selectedRange to timeRange of loadHistories block
        6. Bind output to Data Source of Chart > Series > series
      12. Click Check mark to save symbol
      13. Test functionality
    4. Binding data to header values
      1. Right click topChart > Edit symbol
      2. Open dataflow for current > value
        1. Delete old bind block
        2. Drag in loadValue block
        3. Bind value from list
        4. Bind output of loadvalue block to value text field
          1. Note: this is currently going to miss % symbols
      3. Open datafow for average
        1. Bind output of loadHistory block to input of agg blocks
      4. Open datafow for average
        1. Bind output of loadHistory block to input of agg blocks
      5. Click check mark to save chart symbol
    5. Theme updates
      1. Update colors for bg and text
    6. Chart expander feature
      1. Add a button to expand chart to show a larger view and more information
        1. Right click topChart > edit symbol
        2. Select title group
          1. Vert align: center
        3. Insert group in title
          1. Order: after list
          2. Name: “spreader”
          3. W:2px, H:100%
          4. Flexgrow: 1
        4. Insert image in header
          1. Name: “expanderButton”
          2. Path: empty
          3. W:30px, H:30px
          4. Cursor: mickey mouse hand
        5. Open expanderButton dataflow
          1. Drag in if block
          2. Modify > Edit properties
          3. Bind bgcolor to input0
          4. Bind chart fill color to input1
          5. Then expander-dark.svg
          6. Else expander-light.svg
          7. Close dataflow
            1. Note; if block checks which theme is present and updates image accordingly
      2. Showing expanded graph as a callout
        1. Callouts can only show symbols so we need a symbol to serve as expanded graph
        2. Go to symbols area
        3. Duplicate metricChart
          1. Name: “callout.chart”
          2. Dot will create a folder
          3. We will also add a gauge to that folder
        4. Right click metricChart > edit symbol
        5. Select expanderButton
          1. Callout: Events (furthest right)
            1. Click folder icon
              1. Expand callout folder
              2. Select chart
            2. Position: center
            3. Anchor: center
            4. Relative To: page
            5. Animation speed: 0
            6. Modal callout: enabled
            7. Modal callout fill: #000000
            8. Gray out component: enabled
            9. Double click on show trigger bind
              1. Bind onclick action from expanderButton
            10. Test show and hide functionality
          2. Select callout from under expanderButton
            1. Modify > edit properties
            2. Bind symbol color properties to callout color properties
            3. Right click on callout > edit properties
              1. Now editing callout symbol within symbol.
              2. Bind bg color
              3. Delete list
              4. Add text component for title
              5. Drag in string property
                1. Name: “path”
              6. Open dataflow for title
                1. Split block - separator: “/”
                2. table agg block - column: “value”; method: last
                3. Bind split block output to table agg input
                4. Bind path from symbol properties to split block input
                5. Bind output of table agg to title text field
              7. Open chart dataflow
                1. Bind path to load histories block
              8. Delete expanderButton
              9. Replace with x
                1. Mickey mouse hand
              10. Drag in trigger property
                1. Name: “close”
                2. Bind onclick from x
              11. Select callout_chart
                1. W:auto
              12. Click check mark to save symbol
          3. Select list
            1. Double click on value bind
          4. Select callout
            1. Bind value to path symbol property
          5. Actions: double click on onclick
            1. Bind onclick to show trigger of callout
          6. Select callout, double click close bind
            1. Select expanderButton
              1. Callout: bind close to close trigger callout property
          7. Turn on Preview mode and test functionality
          8. Right click on Symbols > Callout > chart and edit symbol
            1. Resize to desired size.
            2. Click OK
          9. Click OK to save symbol
      3. Adding gauge
        1. Edit callout.chart symbol
        2. Reorg so that chart is now in a horizontal group called “graphs”
        3. Insert group in graphs
          1. Name: “gaugeContainer”
          2. Layout: Absolute
          3. W:auto, H:auto
        4. Insert group in gaugeContainer
          1. Name: “numWrapper”
          2. Layout: Vertical
          3. Horiz align: center
          4. Vert align: center
          5. W:320px, H:320px
        5. Insert text in numWrapper
          1. Name: “current”
          2. Text: “1024”
          3. Font size: 80px
          4. W:auto, H:auto
        6. Right click on numWrapper > convert to symbol
          1. Name: numGauge
        7. Go to symbols and notice that it is under chart now
        8. Double click on numGauge
          1. Change “callout.chart.numGauge” to “callout.numGauge”
        9. Delete numWrapper
        10. Insert symbol in graphs
          1. Name: “gauge”
          2. Symbol: “callout.numGauge”
          3. W:320px, H:320px
        11. Right click on gauge > edit properties
          1. Drag in number property
            1. Name: “current”
          2. Drag in string property
            1. Name: “fontColor”
          3. Bind current to text of current
          4. Bind fontColor to font color of current
        12. Save page
        13. Insert scale track in gaugeContainer
          1. Name: “movingTrack”
          2. Start angle: -160deg
          3. End angle: 160deg
          4. Gradient
            1. Start: #0c81f8
            2. End: #0c81f8
        14. Duplicate movingTrack
          1. Name: “bgTrack”
          2. Gradient
            1. Start: #e1e1e1
            2. End: #e1e1e1
        15. Open dataflow for moving track
          1. Drag in scale block
            1. Input min: 0
            2. Input max: 100
            3. Output min: bound from start angle
            4. Output max: bound from end angle
            5. Bind output to end angle of bgTrack
            6. Modify > edit properties
            7. Bind current to input of scale block
        16. Click OK to save symbol
      4. Rounding
        1. Should this have been done earlier when numbers were originally entered?
    7. Duplicate chart to replace charts on the bottomRow.
