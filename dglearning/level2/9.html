9. Date Picker

  1. Creating the date picker
    1. Insert group in header
      1. Name: “datePicker”
      2. Layout: Absolute
      3. W:200px, H:100%
      4. Position in outline between spreader and the sun image.
    2. Insert Date Range Picker in datePicker
      1. W:100%, H:100%
      2. Turn on preview, show functionality
      3. Difficult to format. Absolute layout of datePicker allows us to cover it with a custom readout.
      4. Change back to Edit mode
  2. Creating the date picker custom readout
    1. Insert group in datePicker
      1. Name: “calendarPicker”
      2. W:100%, H:100%
      3. Horizontal gap: 12px
      4. Advanced Properties
        1. clickThrough: true
    2. Insert image in calendarPicker
      1. Name: “calendar”
      2. Drag in calendar.svg
        1. NOTE: This asset needs to be provided. Current video workflow shows copying from a custom font, which we would need to provide. Probably better to just use an icon like the sun and moon.
      3. W:30px, H:30px
    3. Insert text in calendarPicker
      1. Name: “formattedDate”
      2. Font: lato-semibold
      3. Size: 14px
      4. Color: driven by setFontColor block in toggle dataflow
    4. Select Date Range Picker
      1. Opacity: 0%
  3. Formatting the date
    1. Select Date Range Picker
      1. Date Format String: “MMMM dd, yyyy”
      2. Note changes to formatted output
      3. In Preview mode, click on Date Range Picker and select today.
        1. Note how it shows today twice
    2. Open dataflow for formattedDate
      1. Intent: show one date if only one day is selected, show both dates if range is selected.
      2. Drag in split block
        1. Bind output from Formatted output of Date Range Picker to input of split block.
        2. Separator: “/”
          1. Check table output
          2. There are spaces present in table output cells – will use trim tool to remove them.
          3. Leave table open
      3. Drag in trim block
        1. Name: “trimStartDate”
      4. Duplicate trimStartDate
        1. Name: “trimEndDate”
      5. Connect output cells of split table to inputs of trim blocks
      6. Drag in if block
        1. Operator: =
        2. Input0: trimStartDate output
        3. Input1: trimEndDate output
        4. Then: trimStartDate output
        5. Else: Formatted Value from Date Range Picker
        6. Bind output to text field of formattedDate
    3. Close dataflow/table and change to Preview mode to test functionality
      1. Notice that date does not fit
    4. Open dataflow for formattedDate
      1. Duplicate if block
        1. Then: 180
        2. Else: 320
        3. Bind output to W: of datePicker
    5. Close dataflow/table and change to Preview mode to test functionality
      1. Notice that size changes to accommodate date text size.
