31. Creating the Toggle

The learning objective of Lesson 31 is to practice topics covered in previous lessons by creating groups, assigning properties and binding data.

Lesson 31 will reiterate on the following topics:

  • Group properties
  • Duplicate objects
  • Inserting text in a group
  • Data Binding
  1. Insert text component in toggle group
    1. Name: “readout”
    2. Text unchanged
    3. Font: LatoBlack
    4. Font Size: 12px
    5. Font Color: #333333
    6. Horizontal Alignment: Right
    7. W: 50px H: Auto
  2. Insert group in toggle
    1. Name: “slider”
    2. Layout: Horizontal
    3. Vertical Alignment: Center
    4. Fill Color: #0C81F6
    5. Rounded Corners: 11px
    6. W: 36px H:20px
  3. Insert group in slider
    1. Name: “dot”
    2. Layout: Absolute
    3. Fill: #FFFFFF
    4. Rounded Corners: 100%
    5. W: 16px H: 16px
    6. Left Indent: 2px
      1. New Setting
    7. Effect: Box Shadow
      1. Color: #000000
      2. Opacity: 20%
      3. Y: 2
      4. Blur: 4
  4. Open dataflow of readout
    1. Drag out Diagnostics Mode metric
    2. Drag out if block
      1. Name: “toggleValue”
      2. Connect Diagnostics Mode value to input0 of if block
      3. input1: “true”
      4. then: “enabled”
      5. else: “disabled”
      6. Bind output of if block to text field of readout text component
    3. Duplicate toggleValue
      1. Name: “setColor”
      2. input1: “false”
      3. then: “#CCCCCC”
      4. else: “#0C81F6
      5. Bind to fill color of slider group
  5. Open dataflow of slider
    1. Drag out if block
      1. Name: “position”
      2. Operation: !=
      3. Bind Left Indent value from dot to input0
      4. input1: “18”
      5. then: “18”
      6. else: “2”
    2. Drag out set state block
      1. + Button: 1x
      2. Duration: 0.15
      3. Bind Left Indent from dot to path0 in the properties panel of the state block
      4. Click off state block, click back on state block
        1. Check for change field to no longer be empty
      5. Bind output of if block to change0
      6. Open Actions tab on slider
      7. Bind onclick to invoke button in the properties panel of the state block
    3. Duplicate position block
      1. Name: “toggleBool”
      2. then: “false”
      3. else: “ true”
    4. Drag out a set block from Diagnostic Mode
      1. Right-click on Diagnostics Mode in metrics panel
      2. Drag @Set option to dataflow
      3. Set autorun to true
      4. Bind output of toggleBool block to set block value
  6. Slider – Cursor: Mickey Mouse Hand
    1. New Setting
