30. Usage Group

The learning objective of Lesson 30 is to practice topics covered in previous lessons by creating groups, assigning properties and binding data.

Lesson 30 will reiterate on the following topics:

  • Group properties
  • Inserting text in a group
  • Duplicating objects
  • Data Binding
  1. Fill: No Fill (reset)
  2. Vertical Gap: 20px
  3. Insert group in usage
    1. Name: “disk”
    2. Layout: Vertical
    3. Vertical Gap: 2px
    4. Fill Color: #FFFFFF
    5. W: 100% H: Auto
  4. Insert group in disk
    1. Name: “top”
    2. Layout: Vertical
    3. All Around Pad: 20px
      1. Note setting
      2. W: 100% H: Auto
  5. Duplicate top
    1. Name “bottom”
    2. Layout: Horizontal
    3. Add box shadow
      1. Color: #888888
      2. A: 20%
      3. Y: -1
      4. Blur: 0
  6. Insert text component in top
    1. Name: “title”
    2. Text: “Disk Usage”
    3. Font: LatoRegular
    4. Font Size: 24px
    5. Font Color: #000000
  7. Insert group in top
    1. Name: “gauge”
    2. Layout: Vertical
    3. W: 100% H: Auto
  8. Insert text component in gauge
    1. Name: “percentage”
    2. Font: LatoBlack
    3. Font Size: 12px
    4. Font Color: #000000
    5. Font Horizontal Alignment: Right
    6. Opacity: 50%
    7. W: 100% H: Auto
    8. Bind Disk Usage metric to text field of percentage
      1. Select Formatted from binding dialog
  9. Insert group into gauge
    1. Name: “useBar”
    2. Layout: Absolute
    3. W: 100% H: 12px
    4. Color: #F5F5F5
  10. Insert group in useBar
    1. Name: “blueBar”
    2. Layout: Absolute
    3. Fill Color: 0C81F6
    4. H: 100%
  11. Open blueBar dataflow
    1. Drag out concat block
      1. Bind Disk Usage to input0 on concat block
      2. “%” in input1 field
      3. Bind output of concat block to Width of blueBar
  12. Duplicate percentage
    1. Name: “total”
    2. Bind from Total Disk Space for text field in properties of total text component
  13. Insert group in bottom
    1. Name: “used”
    2. Layout: Vertical
    3. Vertical Alignment: Center
    4. Horizontal Alignment: Center
    5. Vertical Gap: 10px
    6. Top/Bottom Pad: 10px
  14. Insert text component in used
    1. Name: “label”
    2. Text: “used”
    3. Font: LatoBlack
    4. Font Size: 12px
    5. Font Color: #000000
    6. Opacity: 60%
  15. Insert text component in used
    1. Name: “value”
    2. Font: LatoRegular w/ Bold
    3. Font Color: #000000
    4. Font Size: 16px
    5. Opacity: 80%
  16. Open dataflow for value
    1. Drag out Used Disk Space metric
    2. Drag out format number block
    3. Bind value from Used Disk Space to input of format number block
    4. [##,###.##] for Format in format number block
    5. Drag out getNode block
    6. Bind path from Used Disk Space metric to path of getNode
    7. Drag out concat block
    8. Bind ouput of format number block to input0 of concat block
    9. Bind unit of getNode block to input1 of concat block
    10. Bind output of concat block to text field of value text component
  17. Duplicate used
    1. Name: “free”
    2. Drag out Free Disk Space metric
    3. Replace binds
  18. Add box shadow to used
    1. Color: #000000
    2. Opacity: 20%
    3. X: 1
    4. Blur: 1
  19. Duplicate disk group
    1. Rename “memory”
    2. Change title to “Memory Usage”
    3. Bind Memory Usage metric to text field of percentage text component
      1. Select Formatted from the binding dialog
    4. Open blueBar data flow
    5. Replace Disk Usage metric with Memory Usage metric
    6. Drag Memory Usage data block
    7. Bind Total Memory metric to text field of total text component
      1. Select Formatted from the binding dialog
    8. Open dataflow for used value
      1. Replace Used Disk Space metric with Used Memory metric
      2. Change path on getNode block
    9. Open dataflow for free value
      1. Replace Free Disk Space metric with Free Memory metric
      2. Change path on getNode block
