Lessons 16 - 21

This lesson will continue the learning objectives established in lesson 11-15 by creating more parameters of the layout.

Lesson 16-21 will cover

  • Inserting text and groups into groups
  • Positioning elements for layout

16. Insert text component in series

  1. Name: “label”
  2. Text: “Trend”
  3. Font: LatoRegular
  4. Font size: 12px
  5. Font Color: #333333

17. Insert group in legend

  1. Name “readouts”
  2. Layout: Horizontal
  3. Horiz Align: Flex-End
    1. New Setting, similar to right align
  4. Wrap: Wrap
  5. Horizontal Gap: 10px
  6. W: 0px H: auto
  7. Flexgrow: 1

18. Insert group in readouts

  1. Name: “current”
  2. Layout: Horizontal
  3. Horizontal Gap: 10px
  4. W: auto H: auto

19. Insert text component in current

  1. Name: “label”
  2. Color: #333333
  3. Opacity: 60%
  4. Font: LatoBlack
  5. Size: 12px

20. Duplicate label

  1. Name: “value”
  2. Font: LatoRegular w/ Bold
  3. Font Color: #333333
  4. Opacity: 100%

21. Duplicate current

  1. Name: “average”
