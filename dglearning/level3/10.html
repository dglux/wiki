10. Create a dynamic process to create the list that chooses which points will be shown in the graph dropdown selector

  1. Open graphs.dg5
  2. Right click on stage – Select dataflow
    1. On Stage dataflow
      1. Drag and Drop Data Services – DSA – List Node
      2. Drag and Drop System Histories from metrics panel
      3. listNode path: Bind from System History path
        1. Unbind listNode path
          1. This is a way to ensure proper hardcoded path
        2. Mode: points
      4. Delete SystemHistories block from dataflow
      5. Drag and Drop Logic – Repeater
        1. Data: Bind from listNode – output
      6. Drag and Drop Logic – Script
        1. Righ Click on block – Select Convert to Symbol
          1. Name: numCheck
            1. Click Ok
        2. Delete numCheck block
      7. Click on repeater block
        1. Symbol: numCheck
      8. Right click on repeater block – Select Edit symbol
        1. On numCheck dataflow
          1. Drag and Drop Table – Map to Table block
          2. Click on mapToTable – Select output table
            1. Drag table to where you can see it, but it’s not hovering on top of a dataflow. This will make it easier to bind from the table
          3. Drag and Drop Data Service – Load Value Block
          4. Click loadValue block
            1. Mouse to the mapToTable output table you just opened.
            2. Drag and drop the cell from column path and row:0 to the loadValue path
          5. Click on script block
            1. Click on plus
              1. Empty filed: “input”
              2. Type: string
              3. Click Ok
              4. Input: Bind from loadValue value
              5. Autorun: true
              6. Script(expand script first and type in larger window):
                                    if(typeof(@.input) == “number”){
                                    return “=true”
                                    }
                                    return  “=false”
  1. Drag and Drop Table – Column Mapping block
    1. Input: Bind from mapToTable- output
    2. retainColumns: true
    3. name 0: “isNum”
    4. from 0: Bind from script- output
  2. Right click on body of dataflow – Select Symbol Properties
    1. Drag and Drop tabledata to Symbol Properties
      1. Name: “tableOut”
      2. tableOut Property: Bind from tableColumnMapping - output
  3. Click OK in the bottom right corner of the dataflow to save the data symbol
  4. On Stage dataflow
  5. Drag and Drop Table – Aggregation
  6. Input: Bind from repeater – output
  7. Column: “tableOut”
  8. Method: Table Union
  9. Drag and Drop Table – Filter
  10. Input: Bind from tableAggregate - Output
  11. Condition: “isNum == true”
  12. Click on output Table to check that you’re getting what you expect
  13. Drag and Drop Table – Column Mapping
  14. Input: Bind from tableFilter – output
  15. Name 0: listItem
  16. From 0: “= name + “:” + path”
  17. Drag and Drop Table – Aggregation
  18. Input: Bind from tableColumnMapping – output
  19. Column: “listItem”
  20. Method: Concat Unique
  21. Save page
  22. Right click on topRow – topChart Select Symbol Parameters
  23. Drag and Drop string to Symbol Parameters
  24. Name it listItem
  25. Click on metricGraph – title – List
  26. Options: Bind from Symbol Parameters listItem
  27. Close dataflow and system parameters windows
  28. Save symbol by clicking on check mark
  29. Click on Stage – dataflow¬
  30. Click on the last tableAggregation block in the chain
  31. Double click on blue dot of output to hang the output in a separate window
  32. Click on topRow – topChart
  33. In Symbol Properties
  34. listItem: Bind from hanging tableAggregation1.output
  35. Click on bottomRow – leftChart
  36. In Symbol Properties
  37. listItem: Bind from hanging tableAggregation1.output
  38. Click on bottomRow – rightChart
  39. In Symbol Properties
  40. listItem: Bind from hanging tableAggregation1.output
