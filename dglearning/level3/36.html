36. Set the colors of the graph lines and the labels in the trends graph.

  1. Open trends.dg5
    1. Right click on body – chart, select Edit Symbol
      1. Click on trendsGaph – Chart dataflow
        1. Drag and Drop Table Operations – Column Mapping
          1. Input: Bind from histories – output
          2. Retain Columns: true
          3. Name 0: “color”
        2. Drag and Drop Logic – If block
          1. Input 0: Bind from trendsGraph – Symbol Parameters – fontColor
          2. Input 1: “#1d2031”
          3. Then: “= ["#fc9014","#ee3123","#61bb46","#673ab7"][row % 4]”
          4. Else: ”= ["#dd8139","#ff3232","#30d763","#ao6aff"][row % 4]”
          5. Output: Bind to tableColumnMapping – input
      2. Click on tableColumnMapping
        1. Output: Double click on blue binding dot to hang binding window
      3. Right click on trendsGraph – Chart – Series – Series – MasterSeries, select Dataflow
        1. Drag and Drop Table Operations – Select Rows
          1. Input: Bind from tableColumnMapping.output hanging window
          2. Index: Bind from trendsGraph – Chart – Series – Series – MasterSeries - Master Series Properties – Series Index
        2. Close hanging window
        3. Double click on tableSelectRows – output Table to display table
      4. Click on trendsGraph – Chart – Series – Series – MasterSeries
        1. Fil and Stroke Properties
          1. Double click on Border fill
            1. Double click on blue binding dot next to color palette to hang binding box
      5. Drag and Drop cell from tableSelectRows table from column: color. row: 0 to lineStroke.color hanging binding window
      6. Drag and Drop cell from tableSelectRows table from column: name. row: 0 to trendsGraph – Chart – Series – Series – MasterSeries – Series Properties – Display Name
      7. Right click on trendsGraph – header, select Insert- Components – Group
        1. Name: “labels”
        2. Labels
          1. Layout Properties
            1. Layout: Horizontal
          2. Position and Size Properties
            1. W: 100%, H: auto
      8. Right click on trendsGraph – header – label, select Insert – Components – Group
        1. Name: “labelWraper”
        2. labelWraper
          1. Layout Properties
            1. Layout: Horizontal
            2. Horizontal Gap: 10 px
            3. Vert Alignment: Center
      9. Right click on trendsGraph – header – label – labelWraper, select Insert – Components – Group
        1. Name: “color“
        2. color
          1. Layout Properties
            1. Layout: Horizontal
          2. Rounded Corners Properties
            1. Select 1
            2. Corner Radius: “50%”
          3. Position and Size Properties
            1. W: 4px, H: 4px
          4. Fill and Stroke Properties
            1. Set fill to any color as it will be bound by a property later
      10. Right click on trendsGraph – header – label – labelWraper, select Insert – Components – Text
        1. Name: “label”
        2. label
          1. Text and Font Properties
            1. Font: OpenSans-Regular
            2. Font Size: 12
      11. Right click on trendsGraph – header – label – labelWraper, select Insert – Components – Text
        1. Name: “close”
        2. Close
          1. Text and Font Properties
            1. Text: “X”
            2. Font Color: “#ff0000”
            3. Font: OpenSans-Bold
            4. Size: 14
          2. General Properties
            1. Advanced, Display: false
      12. Right click on trendsGraph – header – label – labelWraper, select Convert to Symbol
        1. Name: “colorLabel”
      13. Right click on trendsGraph – header – label – labelWraper, select Delete
      14. Click on Symbols tab
        1. Double lick on trendsGraph – colorLabel
          1. It’s current name is trendsGraph.colorLabel, delete the “trendsGraph.” So it’s just colorLabel
      15. Click on trendsGraph – header – labels
        1. Repeater Properties
          1. Symbol: colorLabel
      16. Right click on trendsGraph – header – labels – renderer, select Symbol Properties
        1. Symbol Parameters
          1. Drag and Drop String
            1. Name: “label”
          2. Drag and Drop String
            1. Name: “color”
          3. Drag and Drop String
            1. Name: “fontColor”
        2. Save colorLabels symbol
      17. Click on trendsGraph – Chart dataflow
        1. Click on columnMaping
          1. Open output table
            1. Column: name – Bind to trendsGraph – header – labels – renderer Renderer Properties – label
            2. Column: color – Bind to trendsGraph – header – labels – renderer Renderer Properties - color
      18. Open project.dg5
        1. Bind fontColor to trendsGraph – header – labels – renderer Renderer Properties – fontColor
      19. Close project.dg5
      20. Right click on trendsGraph, select Edit Properties
        1. Symbol Parameters
          1. Drag and Drop trigger
            1. Name: “remove”
            2. Double click on blue biding dot to hang binding window
          2. Drag and Drop string
            1. Name: “toRemove”
            2. Double click on blue biding dot to hang binding window
      21. Right click on trendsGraph – header – labels – renderer, select Edit Symbol
        1. Right click colorLabel – close, select Dataflow
        2. On dataflow
          1. Drag and Drop Logic – State
            1. Click + button
            2. Duplicate the block twice
          2. State block #1
            1. Name: “setRemove”
          3. State block #2
            1. Name: “setToRemove”
          4. State block #3
            1. Name: “showHide”
          5. setRemove
            1. path 0: Bind from trendsGraph.remove hanging box
            2. click off and on the block
            3. change 0: Click the invoke trigger. It will turn blue/green. This indicates that when the state block is invoked, it will send an invoke action to whatever path is indicated.
            4. Invoke: Bind from colorLabel – close Actions: On Click
          6. setToRemove
            1. path 0: Bind from trendsGraph.toRemove hanging box
            2. click off and on the block
            3. change 0: Bind from colorLabel – label Text and Font Properties: Text
            4. Invoke: Bind from colorLabel – close Actions: On Click
          7. showHide
            1. path 0: Bind from colorLabel – close General Propertis: Advanced, Display
            2. click off and on the block
            3. path 0: Go to Advanced
              1. display: true
              2. original: false
              3. Make sure to click them even if those values are the default. You never want to assume a default Boolean is what it says it is. Some times it’s just interpreting a null. Click it twice if it’s all ready the value you want.
            4. Invoke: Bind from colorLabel Actions: onMouseEnter
            5. Revert: Bind from colorLabel Actions: onMouseLeave
      22. Save symbol
    2. Save symbol
  2. Save page
  3. Go to trends.dg5
    1. Right click on body – chart, select Edit Symbol
      1. Click on trendsGraph – Chart dataflow
        1. Drag and Drop String Operation – Replace block
          1. Input: “name == “<toRemove)” “
          2. Find 0: “<toRemove>”
          3. Replace 0: Bind from trendsGraph Symbol Parameters: toRemove
          4. Output: Bind to tableRemove – condition
        2. tableRemoveRow
          1. invoke: Bind from trendsGraph Symbol Parameters: remove
    2. Save Symbol
  4. Save page
