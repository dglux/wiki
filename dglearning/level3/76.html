76. Create Mailer dataflow that will send emails when alarms are triggered

  1. Navigate to Data tab
  2. Right click on downstream – dataflow, select Create Dataflow
    1. Name: “Mailer”
    2. Click Invoke
  3. Click on downstream – dataflow- Mailer - dataflow
    1. In Data Tab, Right click on downstream – alarming – Alarm Services – metrics, Drag and Drop Stream New Alarms to dataflow
      1. Autorun: true
    2. Navigate back to your Alarms page and create a new Alarm Rule that will trigger an alarm, so this block will have something to return and then return to the Mailer dataflow
    3. Drag and Drop String Operation – Concatenate block
      1. Right click, select Convert to Symbol
        1. Name: “mailer”
    4. Delete mailer block
    5. Drag and Drop Logic – Repeater block
      1. Symbol: mailer
      2. Data: Bind from Stream_New_Alarms – output
    6. Right click on Repeater block, select Edit Symbol
      1. Drag and Drop Table Operations – Map to Table block
        1. Output: Open output table so you can see it
      2. Drag and Drop Logic – Script block
        1. Click + button
          1. Name: “input”
          2. Type: string
        2. Autorun: true
        3. Input: Bind from mapToTable – output Table, cell from column: Watch_Path, row 0
        4. Expand script window
        5. Script: 
                              var path = @.input.split(“/”);
                              path.pop();
                              return path.join(“/”);
  1. Concat
    1. Right Click, select Convert to Symbol
      1. Name” “buildEmail”
  2. buildEmail
    1. Right Click, select Edit Properties
      1. Drag and Drop string
        1. Name: ”sourcePath”
      2. Drag and Drop string
        1. Name: “watchGroup”
    2. Save Symbol
  3. Click on buildEmail
    1. sourcePath appears in Properties on the right
      1. Bind from script – output
      2. Right click, select Pinned
    2. watchGroup appears in Properties on the right
      1. Bind from mapToTable – output Table, cell from column: Watch_Path, row 0
      2. Right click, select Pinned
    3. Right click, Edit Symbol
      1. Drag and Drop String Operations – Split block
        1. Name: “getName”
        2. Input: Bind from Symbol Parameters – sourcePath
        3. Separator: “/”
      2. Drag and Drop Table Operations – Aggregation block
        1. Input: Bind from getName – output
        2. Column: “value”
        3. Method: last
      3. Concat
        1. Name: “buildSubject”
        2. Input 0: Bind from tableAggreagtion – output
        3. Input 1: “” is currently in a state of alarm.”
      4. Drag and Drop String Operations – Concatenate block
        1. Click + button
        2. Input 0: “/downstream/alarming”
        3. Input 1: Bind from Symbol Parameters – watchGroup
        4. Input 2: “/Current Value”
      5. Drag and Drop Data Services – Load Value block
        1. Path: Bind from concat1 – output
        2. Value: Bind to concat – input 2
      6. concat1
        1. Duplicate with (Cntrl + D)
        2. Name: “currentValue”
      7. Concat2
        1. Input 1: Bind from Symbol Parameters – sourcePath
        2. Duplicate with (Cntrl + D) 4 times
      8. loadValue
        1. Duplicate with (Cntrl + D) 4 times
      9. concat2
        1. Name: “email”
        2. Input 2: “/@email”
        3. Output: Bind to loadValue1 – path
      10. Concat3
        1. Name: “operation”
        2. Input 2: “/@operation”
        3. Output: Bind to loadValue2 - path
      11. Concat4
        1. Name: “min”
        2. Input 2: “/Min Value”
        3. Output: Bind to loadValue3 - path
      12. Concat5
        1. Name: “max
        2. Input 2: “/Max Value”
        3. Output: Bind to loadValue4 - path
      13. Concat6
        1. Name: “metric”
        2. Input 2: “/@metric”
        3. Output: Bind to loadValue5 – path
      14. Drag and Drop Logic – If block
        1. Input 0: Bind from loadValue2 – output
        2. Input 1: “<”
        3. Then: Bind form loadValue3
        4. Else: Bind from loadValue4
      15. Drag and Drop String Operation – Concatenate block
        1. Click + button 8 times
        2. Name: “buildBody”
        3. Input 0: Bind from loadValue5 – value
        4. Input 1: “ is currently at “
        5. Input 2: Bind from loadvalue - value
        6. Input 3: “ Which is out of range of the rule: “
        7. Input 4: Bind from loadValue5 – value
        8. Input 5: “ “
        9. Input 6: Bind from loadValue2 – value
        10. Input 7: “ “
        11. Input 8: Bind from if – output
        12. Input 9: “.”
      16. Right click, select Edit Properties
        1. Drag and drop string
          1. Name: “email”
          2. Bind from loadvalue1 - value
        2. Drag and Drop string
          1. Name: “subject”
          2. Bind from buildSubject - output
        3. Name and Drop String
          1. Name: body
          2. Bind from buildbody - output
    4. Save Symbol
    5. buildEmail
      1. email: Right click, select Pinned
      2. subject: Right click, select Pinned
      3. body: Right click, select Pinned
    6. Right click on downstream – mailer – main – Gmail, Drag and Drop a Send block to the dataflow
    7. Drag and Drop Logic – Script block
      1. Click + buttom
        1. Parameter: “input”
        2. Type: string
      2. Autorun: true
      3. Script: “return String(@.input);”
      4. Input: Bind from mapToTable -output Table, cell frpm col: UUID, row: 0
    8. Drag and Drop Logic – Delay block
      1. Delay: 1
      2. Mode: window
      3. Input 0: script1 – output
    9. Send
      1. To: Bind from buildBody – email
      2. Subject: Bind from buildBody – subject
      3. Body: Bind from buildBody – body
      4. Invoke: Bind from delay – output 0
    10. Click on downstream – mailer – main – Gmail
      1. In metrics tab, Drag and Drop User Name to dataflow
        1. Value: Bind to Send – From
  4. Save Symbol
